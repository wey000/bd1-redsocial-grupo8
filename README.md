- Breve Descripción del Caso
El objetivo de este proyecto es diseñar el modelo lógico normalizado de la base de datos para la Red Social Pascualina. Esta plataforma facilitará la comunicación casual, la interacción, la creación de grupos de estudio, las publicaciones y los eventos dentro de la comunidad universitaria.
