Justificación de la Elección de los Tres SGBD
Para soportar la infraestructura de la Red Social Pascualina se seleccionaron los siguientes motores de base de datos:
1. **MariaDB (SGBD 1):** Elegido por su ligereza, compatibilidad con MySQL y facilidad de despliegue mediante entornos locales como XAMPP.
2. **PostgreSQL (SGBD 2):** Seleccionado por su capacidad empresarial, adherencia estricta a los estándares SQL y su avanzado soporte nativo para JSON/JSONB.
3. **Microsoft SQL Server (SGBD 3):** Incluido para evaluar entornos corporativos con fuerte integración en plataformas de desarrollo en C# y Visual Studio.
